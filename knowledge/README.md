# The knowledge folder

This is where the user's own data lives, and it is what makes the posts sound
like them. Everything here is plain text the user can read and edit.

Fill these files in before writing much content:

- `brand-voice.md` - how the user sounds.
- `platforms.md` - which platforms are connected and what each is for.
- `content-pillars.md` - the themes the user posts about.
- `past-posts.md` - their best and most recent posts.
- `cadence.md` - how often and when they post.
- `ingest-log.md` - a running list of what has been learned and from where.

Rules: never store passwords or keys here, and never overwrite something the
user wrote with an assumption - add a line marked `(draft - confirm)` instead.
